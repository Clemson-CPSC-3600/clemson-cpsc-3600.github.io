CPSC 3600: Computer Networks

CPSC 3600: Computer Networks

Clemson University | School of Computing

An introduction to computer networks with emphasis on the Internet architecture, protocols, and network applications. Topics include application layer protocols, transport layer services, network layer routing, link layer technologies, and network security fundamentals.

Course Modules

What You'll Learn

🌐

Internet Architecture

Understand how the Internet is structured, from edge networks to the core

📡

Protocol Layers

Master the five-layer protocol stack and how data flows through networks

⚡

Network Performance

Learn to analyze delay, throughput, and optimize network performance

🔐

Security Fundamentals

Explore encryption, authentication, and secure communication protocols
