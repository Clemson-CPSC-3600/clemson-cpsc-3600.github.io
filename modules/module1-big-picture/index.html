The Big Picture

Explore the fundamental structure of the Internet, understand how protocol layers organize network functionality, and learn to analyze network performance through delay and throughput calculations.

Learning Objectives

  • Describe the structure of the Internet, including edge, core, and ISP hierarchy
  • Explain the purpose and function of protocol layers in network communication
  • Calculate network performance metrics including delay and throughput
  • Analyze how different delay components affect end-to-end latency
  • Understand the relationship between bandwidth, throughput, and network congestion

Topics Covered

  • Internet structure (edge, core, ISP hierarchy)
  • Protocol layering and encapsulation
  • Network performance metrics
  • Delay and throughput calculations
