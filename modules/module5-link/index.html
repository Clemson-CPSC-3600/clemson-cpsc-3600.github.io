Link Layer

Explore the link layer technologies that enable local network communication. Learn about Ethernet framing, self-learning switches, spanning tree protocol, collision detection, encoding, ARP, and WiFi/wireless LANs.

Learning Objectives

  • Understand link layer services and responsibilities
  • Explain Ethernet protocol and frame structure
  • Describe self-learning switches and spanning tree protocol
  • Analyze collision detection and management (CSMA/CD)
  • Master encoding and framing techniques
  • Explain ARP protocol and address resolution
  • Understand WiFi and wireless LAN technologies
