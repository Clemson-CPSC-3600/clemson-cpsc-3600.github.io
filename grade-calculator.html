About Specification Grading

Understanding the Bundle System

Project Bundles

Project bundles must be completed sequentially—you cannot earn credit for Bundle 2 without first completing Bundle 1.

  • Bundle 1: Core functionality and basic test cases
  • Bundle 2: Intermediate features and edge case handling
  • Bundle 3: Advanced features and comprehensive testing

Exam Bundles

Exam bundles are graded independently. Roughly 80% mastery = Satisfactory.

  • Bundle 1: Multiple choice and short answer (foundational knowledge)
  • Bundle 2: Problem-solving questions (application)
  • Bundle 3: Code comprehension (current project concepts)
Resubmission Policies
  • Projects: 24-hour late window (no penalty) + 3-day resubmission window for Unsatisfactory bundles
  • Exams: Retake Unsatisfactory bundles from Exams 1-2 during the final exam period
  • Network Analysis: 24-hour late window + 3-day resubmission window after grades released
  • Exit Checks: Cannot be resubmitted, but 3 automatic drops allowed
Example Scenarios
  • D Grade (14 pts): All Project Bundle 1s (3 pts) + Exam 1-2 Bundles 1-2 (4 pts) + Exam 3 Bundle 1 (1 pt) + All Network Analysis (5 pts) + 1 Exit Check point
  • C Grade (17 pts): Two complete Projects (6 pts) + All Exam Bundle 1s (3 pts) + Two Exam Bundle 2s (2 pts) + 4 Network Analysis (4 pts) + 2 Exit Check points
  • B Grade (20 pts): Two complete Projects (6 pts) + Two complete Exams (6 pts) + Exam 3 Bundle 1 (1 pt) + All Network Analysis (5 pts) + 2 Exit Check points
  • A Grade (23 pts): All Projects (9 pts) + Two complete Exams (6 pts) + Exam 3 Bundles 1-2 (2 pts) + 4 Network Analysis (4 pts) + 2 Exit Check points
